# StockSense

### 📦 Inventory Management, Simplified.

StockSense is a modern inventory management system designed to help warehouse teams monitor products, track stock levels, manage inventory operations, and identify products that need attention.

Built as a collaborative hackathon project, StockSense focuses on making everyday inventory management simple, organized, and easy to understand.

---

## 📌 Overview

Managing inventory becomes increasingly difficult as the number of products and warehouse operations grows.

StockSense brings the most important inventory information into a single dashboard, allowing users to quickly understand:

- What products are available
- How much stock is currently available
- Which products are running low
- What inventory activity happened recently
- Which warehouse is currently selected

The goal is simple:

> **Give inventory managers the information they need, when they need it.**

---

## ✨ Key Features

### 📊 Dashboard

The dashboard provides a quick overview of the current inventory state.

It displays:

- Total number of products
- Total available stock
- Low-stock products
- Recent stock movements
- Warehouse selection

Everything important is available at a glance without requiring users to navigate through multiple pages.

---

### 📦 Product Management

Products can be managed from a dedicated Products section.

Users can:

- ➕ Add new products
- 🔎 Search for products
- ✏️ Edit existing products
- 🗑️ Delete products
- View product SKUs
- View product categories
- Monitor current stock
- Set reorder levels

---

### 🔎 Product Search

Finding a product shouldn't require scrolling through a long list.

The Products page allows users to search by:

- Product name
- SKU
- Category

---
